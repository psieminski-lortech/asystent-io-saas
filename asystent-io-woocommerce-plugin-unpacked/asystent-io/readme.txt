== Description ==

Asystent.io to narzędzie AI, które wykrywa moment, w którym klient zamierza opuścić Twój sklep z pełnym koszykiem — i wyświetla mu spersonalizowany popup z ofertą.

**Jak to działa:**

1. Lekki skrypt JS wykrywa intencję wyjścia (ruch kursora, scroll, zmiana zakładki)
2. AI analizuje zawartość koszyka i kontekst
3. Generuje spersonalizowaną ofertę (darmowa dostawa, rabat, social proof)
4. Klient wraca do zakupu lub zostawia email

**Funkcje:**

* Exit-intent detection na desktop i mobile
* AI generuje treść popup'u w czasie rzeczywistym
* Automatyczna strategia: darmowa dostawa lub rabat
* Popup dopasowany do kolorystyki sklepu
* Zbieranie leadów email (integracja z Formspree)
* Dashboard z analityką konwersji
* Konfiguracja strategii w panelu WordPress

== Installation ==

1. Pobierz plik ZIP wtyczki
2. W panelu WordPress przejdź do Wtyczki → Dodaj nową → Wyślij wtyczkę
3. Zainstaluj i aktywuj
4. Przejdź do Asystent.io w menu bocznym
5. Wklej klucz API z panelu asystent.io
6. Gotowe!

== Frequently Asked Questions ==

= Czy potrzebuję konta na asystent.io? =
Tak, klucz API jest wymagany. Zarejestruj się na asystent.io.

= Czy wtyczka spowalnia stronę? =
Nie. Skrypt waży <8KB i ładuje się asynchronicznie (defer).

= Czy działa na mobile? =
Tak. Wykrywamy intencję wyjścia również na urządzeniach mobilnych.
